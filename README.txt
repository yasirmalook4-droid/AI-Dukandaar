AI DUKANDAAR - INSTALL (offline app on phone)
1. Upload this whole folder to any free HTTPS hosting (Netlify Drop, GitHub Pages, Cloudflare Pages). Keep all files together.
2. Open the https link in Chrome on the phone -> menu (3 dots) -> 'Install app' / 'Add to Home screen'.
3. Open it once with internet; after that it works fully offline from the home-screen icon.
4. Do this on every phone (Master + Cashiers). Use More > Sync devices to merge sales.
Data is stored on each phone. Export a backup regularly (More > Backup).
Want a real .apk? Give the hosted link to pwabuilder.com and download the Android package.
